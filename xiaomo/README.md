# 小忠岳

- 桌宠 ID：`xiaomo`
- 风格：白衬衫、眼镜男生风格
- 文件：`pet.json`、`spritesheet.webp`

## 安装

将整个 `xiaomo/` 目录复制到 `${CODEX_HOME}/pets/xiaomo/`。未设置 `CODEX_HOME` 时，默认路径为 Windows 的 `C:\Users\<用户名>\.codex\pets\xiaomo\`，或 macOS / Linux 的 `~/.codex/pets/xiaomo/`。

不要把 `pet.json` 和 `spritesheet.webp` 直接放在 `pets/` 根目录；应用会按 `xiaomo` 子目录加载这只桌宠。
