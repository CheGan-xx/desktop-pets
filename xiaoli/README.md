# 小莉

- 桌宠 ID：`xiaoli`
- 风格：像素风毕业纪念女孩，带相机
- 文件：`pet.json`、`spritesheet.webp`

## 安装

将整个 `xiaoli/` 目录复制到 `${CODEX_HOME}/pets/xiaoli/`。未设置 `CODEX_HOME` 时，默认路径为 Windows 的 `C:\Users\<用户名>\.codex\pets\xiaoli\`，或 macOS / Linux 的 `~/.codex/pets/xiaoli/`。

不要把 `pet.json` 和 `spritesheet.webp` 直接放在 `pets/` 根目录；应用会按 `xiaoli` 子目录加载这只桌宠。
